## Суть бага

При симуляции будущего (ползунки «дней прошло» / «целевая цена») калькулятор проецирует
подразумеваемую волатильность (IV) опциона на будущую дату. Когда нет калибровочных
параметров тикера (OU-модель), включается запасная эвристика: «IV растёт по мере
приближения к экспирации» — до +50% к базовой IV.

Эта эвристика не подтверждается рынком для дальних OTM-опционов и систематически
**завышает** прогнозную стоимость купленных опционов, то есть занижает убыток.

Реальный пример (ADBE, dbConfig `52553518-4846-4c46-a64b-48ba98916637`): вход 11.06.26
при 71 дне до экспирации, IV входа ~49-51%. Симуляция «сегодня» (прошло 44 дня, осталось 27)
даёт множитель ×1.192 → прогнозная IV ~59-60%, тогда как рыночная IV осталась ~46-49%.
Колонка Start P&L показывала −$2 259 против факта −$3 224. При «плоской» IV расчёт даёт
−$3 061 — практически попадание.

## Принятое решение

Заменить запасную эвристику роста на нейтральную: **в отсутствие данных IV остаётся
равной базовой (входной) IV**. Пути OU-модели (калиброванные тикеры) и интерполяции по
реальной поверхности волатильности не трогаем.
