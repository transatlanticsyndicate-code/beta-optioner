# 🔧 Исправление кнопки сброса калькулятора

**Статус:** 🔴 Не начато

---

## 📋 Описание проблемы

**Где:** Страница "Универсальный калькулятор опционов"  
**URL:** https://beta.optioner.online/tools/universal-calculator  
**Кнопка:** Оранжевая кнопка сброса (иконка RotateCcw)

**Проблема:**
- Кнопка сброса должна полностью очищать калькулятор
- По факту: иногда просто перезагружает страницу, но калькулятор остаётся заполненным предыдущими данными
- Ожидаемо: чистая страница, как при первом открытии https://beta.optioner.online/tools/universal-calculator

**Причина:**
Функция `resetCalculator` в файле `UniversalOptionsCalculator.jsx` (строки 723-775):
1. Очищает все state переменные
2. Очищает localStorage (`calculatorState`, `optioner_user_overrides`)
3. Очищает URL параметры
4. Вызывает `clearExtensionData()`
5. **НО:** не делает принудительную перезагрузку страницы

После очистки state, компонент остаётся смонтированным. `useEffect` (строка 1240) может снова загрузить старые данные из localStorage или extension data, потому что:
- Очистка localStorage ещё не завершилась (асинхронность)
- Или данные восстанавливаются из другого источника

---

## ✅ Решение

Добавить **принудительную перезагрузку страницы** после очистки всех данных:

```javascript
// В конце функции resetCalculator (после всех очисток)
setTimeout(() => {
  window.location.reload();
}, 100);
```

**Почему setTimeout:** Дать всем очисткам завершиться синхронно перед перезагрузкой.

**Почему reload():** Полная перезагрузка страницы гарантирует, что компонент инициализируется с чистого состояния, без восстановления из кэша или localStorage.

## 📝 План работ

### 1. Исправление кода (Frontend)

**Файл:** `frontend/src/pages/UniversalOptionsCalculator.jsx`

**Изменения:**
- Добавить `window.location.reload()` в конец функции `resetCalculator`
- Добавить комментарий, объясняющий зачем это нужно

**Пример:**
```javascript
const resetCalculator = useCallback(() => {
  // ... все существующие очистки ...
  
  // Сбрасываем сделку
  setDealInfo(null);
  setActiveCalculatorTab('calculator');
  
  // ✅ НОВОЕ: Принудительная перезагрузка страницы
  // ЗАЧЕМ: Гарантируем полную очистку состояния, предотвращаем восстановление данных из useEffect
  setTimeout(() => {
    console.log('🔄 [Universal] Перезагрузка страницы после сброса...');
    window.location.reload();
  }, 100);
}, [clearExtensionData]);
```
