# Feature: колонка «Start IV» в таблице опционов

**Дата:** 2026-07-25
**Файл:** `frontend/src/components/CalculatorV2/OptionsTableV3.jsx`
**Статус:** BUILD done

## Что добавлено

В таблицу опционов (OptionsTableV3) добавлена новая колонка **«Start IV»**,
расположенная сразу после колонки «Fact IV». Колонка полностью read-only —
никаких инпутов, ничего не пересчитывает и не влияет на логику P&L/Start P&L.

## Зачем

Заказчик при входе в сделку фиксирует реальную волатильность из терминала
брокера. Эта волатильность замораживается в снимке ноги (`option.startSnapshot`)
в момент сохранения позиции. До этой фичи снимок использовался только для
расчёта «Start P&L», а сама зафиксированная IV нигде не отображалась.
Колонка «Start IV» показывает эту точку отсчёта и дельту к текущей Fact IV,
чтобы можно было визуально анализировать сделки — как изменилась волатильность
с момента входа в позицию.

## Источник данных

Значение берётся из `option.startSnapshot` (не пересчитывается заново):

1. Если есть `startSnapshot.manualIvOverride` — используется оно (значение уже
   в процентах, например `44.82`).
2. Иначе, если есть `startSnapshot.impliedVolatility` — используется оно;
   если оно меньше 1 (доля, например `0.4482`), домножается на 100.
3. Если снапшота нет вовсе (старые сделки, сохранённые до появления снимков) —
   отображается прочерк «—».

Дельта считается как `option.manualIvOverride (текущая Fact IV) − Start IV` и
показывается компактно под значением (например `+9.1` или `−4.3`), только если
обе величины присутствуют. Цвет дельты — по выгоде для направления ноги:

- **Buy**: рост IV с момента входа — зелёный (выгодно), падение — красный.
- **Sell**: наоборот — рост IV — красный, падение — зелёный.

Использованы те же классы цвета, что и в остальной таблице (`text-green-600` /
`text-red-600`, как в P&L).

## Поведение для старых сделок

Если у ноги нет `startSnapshot` (сохранена до появления функционала снимков),
колонка показывает «—» без дельты — никаких ошибок и NaN.

## Вёрстка

- Колонка узкая (`minmax(0,0.55fr)`), как соседняя «Fact IV» — добавлен один
  токен в `gridTemplateColumns` во всех трёх местах, где используется эта
  сетка: заголовок, строка опциона, строка ИТОГО.
- В строке ИТОГО для этой колонки ничего не выводится (пустая ячейка) — по
  требованию, колонка не участвует в агрегации.
- Проверено визуально по структуре: количество колонок в заголовке, строке
  опциона и строке ИТОГО совпадает (20 колонок: 18 фиксированных + 2
  опциональные — Премия/OI).
