# Подсказка «i» для «Тип позиции» + депозит в еженедельной статистике

Дата: 2026-09-22
Проект: crypto.optioner.online
Источник: две просьбы заказчика (скриншоты от 03:18 и 03:27)

## Задача 1 — подсказка «i» у колонки «Тип позиции»

Сейчас в шапке таблицы подсказка есть только у колонки «Сценарий»: при наведении
на иконку «i» видно, сколько позиций открыто по каждому сценарию.

Нужно то же самое для колонки «Тип позиции»: при наведении — список
«Название типа: количество».

Решения, принятые с заказчиком:
- считаем **только активные** позиции — так же, как в подсказке по сценариям,
  чтобы цифры в двух подсказках сходились между собой;
- позиции без типа (или со ссылкой на удалённый тип) показываем отдельной
  строкой «Без типа» и только если такие есть;
- порядок строк — как в списке типов в настройках, «Без типа» последней;
- внешний вид, поведение при наведении и стили — те же, что у подсказки
  по сценариям (повторно используются существующие классы).

Ограничение: заголовок «Тип позиции» кликабелен (переключает сортировку),
поэтому клик по иконке не должен менять сортировку.

Где считать: в общем расчёте статистики, рядом с разбивкой по сценариям.
Так обе подсказки всегда берут один и тот же набор активных позиций.
Альтернатива — считать внутри таблицы — отклонена: со временем даёт расхождения.

## Задача 2 — депозит во вкладке «Еженедельная статистика»

Карточка «Депозит» в этой вкладке уже реализована и считается тем же способом,
что во вкладке «Финансовый учёт» (ввод минус вывод средств), но скрыта стилем
со времён переноса проекта в монорепозиторий.

Нужно: показать карточку первой в ряду и привести написание суммы к виду
«$2 154 159» — как в остальных счётчиках этой вкладки.

## Критерии приёмки

1. В шапке таблицы у «Тип позиции» есть иконка «i»; при наведении показывается
   список типов с количеством активных позиций.
2. Сумма чисел в подсказке по типам равна сумме чисел в подсказке по сценариям.
3. Клик по иконке «i» не меняет сортировку колонки.
4. Числа в подсказке совпадают со счётчиком «Позиций» в настройках типов
   (с поправкой на неактивные позиции).
5. Во вкладке «Еженедельная статистика» видна карточка «Депозит», её значение
   совпадает с карточкой «Депозит» во вкладке «Финансовый учёт».
6. Ряд карточек не разъезжается на узком экране.
7. Сборка проходит без ошибок, в консоли браузера нет ошибок.

## Вне объёма

- Изменение логики расчёта депозита.
- Изменение подсказки по сценариям.
- Любые правки формата чисел в других вкладках.
