# Сделка только из Call — режим «Без Put» в подборе СЕВЕР GPT

Дата: 2026-08-09
Источник ТЗ: Google Doc «Сделка_только_Call»

## SPEC

**Задача.** Уметь считать сделку, собранную только из купленных Call.

**Как было.** Диапазон страйков Put в форме «СЕВЕР GPT» обязателен: если очистить поля,
появляется ошибка «Диапазон страйков Put задан некорректно» и кнопка подбора заблокирована.
Дополнительно фильтр «Допустимый диапазон P&L по низу ±» требует, чтобы на нижней цене позиция
закрывалась около нуля — для чистого Call это невозможно, приходилось вручную ставить 10000.

**Решения заказчика.**
1. Put отключается галочкой (не пустыми полями).
2. Поле «Допустимый диапазон P&L по низу ±» в этом режиме убирается; максимальный убыток
   чистого Call равен уплаченной премии и показывается на карточке результата.

**Логика подбора** остаётся в пользовательском промпте («Тест_только Call» в библиотеке промптов) —
код её не задаёт.

**Критерии приёмки.**
- Галочка «Без Put» скрывает поля диапазона Put и допуска P&L по низу, кнопка подбора активна.
- В запрос к ChatGPT не уходят Put: ни строки цепочки, ни диапазон страйков, ни допуск по низу.
- Даже если модель пришлёт ногу Put — она не попадёт в сделку.
- На карточке результата — только Buy Call и подпись «максимальный убыток — уплаченная премия $X».
- Прежний сценарий (Call + Put) не меняется.
