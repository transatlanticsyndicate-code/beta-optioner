# Fix: неверные даты экспирации в списке для стратегии СЕВЕР GPT

**Дата:** 2026-08-27
**Тип:** /fix
**Скоуп:** `EXTENTIONS/OptionsCPbuttons/src/northSupport.js` (1.7.1 → 1.7.2)

## Симптом

В поп-апе «Стратегия СЕВЕР GPT» дропдаун экспираций показывает даты, которых нет в
TradingView: несуществующие дни (`2026-09-48`, `2027-10-94`) и сдвинутые годы
(`2027-09-18` вместо `2026-09-18`). Воспроизведено заказчиком на NRG и UCTT.

## DIAGNOSE

### Корневая причина

`parseGroupCellDate()` разбирает **склеенный** `textContent` группового заголовка
таблицы. В новой вёрстке TradingView рядом с датой стоит бейдж «N DTE» отдельным
элементом, и `textContent` соединяет их без пробела:

```
"Sep 4" + "8 DTE"  → "Sep 48 DTE"
"Sep 18" + "22 DTE" → "Sep 1822 DTE"
```

Дальше:
1. regex дня `(\d{1,2})` откусывает `48` / `18` → день 48 (мусор) либо верный день;
2. regex бейджа `(\d+)\s*DTE` захватывает склейку → DTE 48 / 1822 (мусор);
3. подбор года минимизирует `|разница_в_днях − DTE|`, а DTE испорчен → выбирается
   самый дальний год (2027) вместо верного 2026.

Обе цифры искажаются одной и той же склейкой — отсюда и «48 сентября», и год 2027.

### Почему вообще используется этот код

`parseGroupCellDate()` — **резервный** источник списка. Основной (поповер фильтра
Expiration с машиночитаемым `data-qa-id ...;YYYYMMDD`) даёт корректные даты, но
`dumpExpirationsList()` вызывается на каждую перерисовку таблицы и запускает
чтение поповера параллельно самому себе: одна копия открывает поповер, вторая
закрывает его по Escape → `getDateOptionItems()` возвращает пусто → падение в
резервный источник с испорченными датами. Отсюда же и неполный список (в таблице
отрисованы не все группы) — на UCTT в дропдауне 3 даты из 4.

### Воспроизведение

1. Открыть доску опционов TradingView для NRG (или UCTT) с установленным расширением.
2. Дождаться дампа списка экспираций (`tvc_expirations_list`).
3. В калькуляторе открыть «Стратегия СЕВЕР GPT» → дропдаун дат.
4. Ожидалось: даты из TV (2026-09-04, 2026-09-11, …). Фактически: 2026-09-48, 2027-09-11, …

### Затронутые файлы

- `EXTENTIONS/OptionsCPbuttons/src/northSupport.js` — разбор заголовков, дедуп чтения поповера.
- `EXTENTIONS/OptionsCPbuttons/manifest.json` — версия.

## FIX

1. Текст группового заголовка собирается по текстовым узлам через пробел
   (`groupCellText()`), а не берётся из `textContent` — дата и бейдж DTE больше не
   слипаются. Используется и в `readExpirationsFromTable()`, и в `findGroupCellElement()`.
2. `parseGroupCellDate()` отбраковывает невозможные дни (день вне 1..31 и
   переполнение месяца) — мусорная дата теперь не попадает в список вообще.
3. Чтение поповера дедуплицируется in-flight промисом: параллельные вызовы
   `dumpExpirationsList()` ждут один и тот же результат и не закрывают поповер
   друг у друга — основной (корректный и полный) источник перестаёт срываться.

## VERIFY

- Живая проверка заказчиком на NRG и UCTT: список дат в дропдауне совпадает с
