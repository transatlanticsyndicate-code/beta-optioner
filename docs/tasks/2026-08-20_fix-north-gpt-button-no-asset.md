# Fix: кнопка «СЕВЕР GPT» без добавления актива

**Дата:** 2026-08-20
**Тип:** /fix

## Что было
Кнопка «СЕВЕР GPT» в шапке таблицы опционов появлялась только после добавления
лонг-позиции по базовому активу. Правило осталось со времён, когда стратегия
работала исключительно «поверх» купленного актива.

## Корневая причина
Условие показа кнопки (`canShowNorthGptButton` в UniversalOptionsCalculator)
требовало наличия лонг-позиции (`longPositionsEntry`). После введения режимов
стратегии («Только опционы» — режим по умолчанию, «Только CALL»,
«Актив + опционы», где актив добавляет сама стратегия) это требование устарело.

## Что изменено
- Из условия показа кнопки убрано требование лонг-позиции по активу.
  Остались актуальные условия: подходящий режим калькулятора
  (акции/ETF/крипта/фьючерсы), выбранный тикер с ценой (>0) и пустая таблица
  опционов (после применения комбинации кнопку заменяет бейдж стратегии).
- Обновлён устаревший комментарий в NorthGptButton.jsx.

## Как проверено
- Все фронтенд-тесты: 29 сьютов, 274 теста — зелёные.
- Диалог стратегии и так корректно работает без актива:
  `entryPrice` падает на текущую цену, `assetQuantity = 0`,
  режим по умолчанию — «Только опционы».

## Безопасность
Правка убирает только UI-условие видимости кнопки, новых входных данных и
запросов не добавляет — уязвимостей не вносит.
