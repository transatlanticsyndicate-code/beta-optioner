# Калькулятор P&L опционов — Техническое описание

## Назначение

Инструмент для расчёта прибыли/убытка по опционной позиции на криптовалюту (ETHUSDT) на Binance. Пользователь вводит параметры своей позиции один раз, затем видит результаты расчёта одновременно для 4 сценариев («срезок») — разных дат и цен актива в будущем.

---

## Математическая модель

Расчёт цены опциона производится по модели **Блэка-Шоулса** (Black-Scholes).

### Формулы

```
d1 = ( ln(S/K) + (r + σ²/2) × T ) / ( σ × √T )
d2 = d1 - σ × √T

CALL = S × N(d1) - K × e^(-rT) × N(d2)
PUT  = K × e^(-rT) × N(-d2) - S × N(-d1)
```

где:
- `S` — текущая цена актива
- `K` — страйк
- `T` — время до экспирации в годах (от даты срезки до даты экспирации)
- `r` — безрисковая ставка (дробь, напр. 0.037)
- `σ` — волатильность IV (дробь, напр. 0.80)
- `N(x)` — функция стандартного нормального распределения CDF

При `T = 0` (дата экспирации наступила): возвращается внутренняя стоимость — `max(S−K, 0)` для CALL, `max(K−S, 0)` для PUT.

### Расчёт P&L

```
Цена опциона в срезке  = BS(scenSpot, K, T_scen, r, σ, type)
P&L на контракт        = Цена опциона в срезке − Премия уплаченная
Итого P&L              = P&L на контракт × Кол-во контрактов
Безубыток (экспирация) = K + Премия  (для CALL)
                       = K − Премия  (для PUT)
```

Размер контракта фиксирован: **1 контракт = 1 ETH** (стандарт Binance).

## Структура интерфейса

### Блок 1: Параметры позиции

Один блок во всю ширину страницы. Все поля расположены в одну строку (CSS Grid, 9 колонок).

| ID поля     | Название           | Тип     | По умолчанию     | Шаг     |
|-------------|--------------------|---------|------------------|---------|
| `optType`   | Тип                | select  | CALL             | —       |
| `spot`      | Цена актива        | number  | пусто            | 1       |
| `strike`    | Страйк             | number  | пусто            | 1       |
| `buyDate`   | Дата покупки       | date    | сегодня (авто)   | —       |
| `expiry`    | Дата экспирации    | date    | пусто            | —       |
| `premium`   | Премия (USDT)      | number  | пусто            | 0.01    |
| `iv`        | IV (% год.)        | number  | пусто            | 1       |
| `rf`        | Ставка (%)         | number  | 3.7              | 0.1     |
| `qtyGlobal` | Кол-во контр.      | number  | пусто            | 1       |

**Поведение:** при изменении любого поля все 4 срезки пересчитываются автоматически (события `input` и `change`).

**Дата покупки** устанавливается в сегодняшнее число через JS при загрузке страницы (`toYMD(today())`).

---

### Блок 2–5: Срезки (4 штуки)

Каждая срезка — отдельный блок-карточка, расположенный под блоком параметров. Карточки идут одна под другой во всю ширину.

Визуально: слева большой серый номер (1–4), справа заголовок `// СРЕЗКА N`, затем поля и строка результатов.

#### Поля каждой срезки

| ID поля      | Название                       | Тип    | По умолчанию             | Примечание                              |
|--------------|--------------------------------|--------|--------------------------|-----------------------------------------|
| `qty{n}`     | Кол-во контрактов              | number | пусто                    | Если пусто — берётся `qtyGlobal`        |
| `sspot{n}`   | Цена актива на СРЕЗКУ          | number | пусто                    | —                                       |
| `sdate{n}`   | Дата СРЕЗКИ                    | date   | сегодня + N дней         | Синхронизировано с полем дней           |
| `sdays{n}`   | Дней от сегодня                | number | 30 / 60 / 90 / 120       | Шаг стрелок: 30. Синхронизировано с датой |

#### Синхронизация дата ↔ дни

- При изменении поля **дней** → дата пересчитывается как `сегодня + N дней`
- При изменении поля **даты** → дни пересчитываются как `(дата − сегодня) в днях`
- После любого изменения сразу вызывается `calcSlice(n)`

#### Логика выбора количества контрактов

```javascript
const qtyLocal  = document.getElementById(`qty${n}`).value;
const qty       = qtyLocal !== '' ? parseInt(qtyLocal) : qtyGlobal;
```

Если поле срезки заполнено — используется оно. Иначе — глобальное значение из блока параметров.

---

### Строка результатов (внутри каждой срезки)

Появляется сразу под полями срезки после расчёта. Содержит 5 метрик + блок безубытка:

| Метрика              | Описание                                              | Цвет                  |
|----------------------|-------------------------------------------------------|-----------------------|
| Цена опциона         | Теоретическая цена по BS на дату срезки               | нейтральный (#1a1a2e) |
| P&L / контракт       | `scenPrice − premium`                                 | зелёный / красный     |
| Итого P&L ×{qty}     | `pnlPerContract × qty`                                | зелёный / красный     |
| Дней прошло          | `scenDate − buyDate` в днях                           | нейтральный           |
| До экспирации        | `expDate − scenDate` в днях                           | нейтральный           |
| Безубыток            | Справа: `K + premium` (CALL) или `K − premium` (PUT)  | акцентный (#007a52)   |

## Дизайн и стилизация

### Цветовая схема (светлая тема)

```css
--bg:      #f4f4f0   /* фон страницы */
--surface: #ffffff   /* фон карточек */
--border:  #dcdcd4   /* границы */
--accent:  #007a52   /* зелёный акцент, прибыль */
--text:    #1a1a2e   /* основной текст */
--muted:   #8888a0   /* подписи полей */
--profit:  #007a52   /* прибыль */
--loss:    #cc1133   /* убыток */
```

### Фон страницы

Декоративная сетка через `body::before` — тонкие линии rgba(0,122,82,0.06) с шагом 40px.

### Типографика

- Основной шрифт: `Space Mono` (Google Fonts, 400/700) — все тексты, поля, числа
- Номера срезок: `DM Serif Display` — декоративный большой номер (34px, цвет #d8d8d0)

### Карточки

- `border-radius: 12px`, `padding: 24px 28px`, `margin-bottom: 16px`
- Срезки дополнительно имеют `border-left: 3px solid #007a52`
- Анимация появления: `slideUp` (opacity 0→1, translateY 14px→0, 0.5s)

### Адаптивность

- Блок параметров: 9 колонок → 4 колонки (≤900px) → 2 колонки (≤500px)
- Блок срезки: 3 колонки → 2 колонки (≤700px)

## Зависимости

- Нет внешних JS-библиотек (Chart.js удалён)
- Google Fonts: `Space Mono` + `DM Serif Display` (подключаются через `<link>`)
- Весь JS — нативный, без фреймворков

## Файловая структура

Весь код — один самодостаточный HTML-файл. При интеграции на сайт можно:

1. **Вариант A** — вставить содержимое `<style>` в CSS-файл сайта, содержимое `<script>` в JS-файл, HTML-разметку в нужный раздел страницы.
2. **Вариант B** — встроить как `<iframe>` с файлом.
3. **Вариант C** — переписать под фреймворк (React, Vue и т.д.), логика расчётов остаётся идентичной.

## Ключевые JS-функции

| Функция           | Назначение                                                        |
|-------------------|-------------------------------------------------------------------|
| `bs(S,K,T,r,σ,type)` | Расчёт цены опциона по Блэку-Шоулсу                          |
| `normCDF(x)`      | CDF стандартного нормального распределения (через approximation erf) |
| `erf(x)`          | Функция ошибок (аппроксимация Абрамовица и Стегана)              |
| `calcSlice(n)`    | Расчёт и рендер результатов для срезки номер n (1–4)             |
| `calcAll()`       | Вызывает `calcSlice` для всех 4 срезок                           |
| `onSDaysChange(n)`| Синхронизация: дни → дата для срезки n                           |
| `onSDateChange(n)`| Синхронизация: дата → дни для срезки n                           |
| `toYMD(d)`        | Конвертация Date в строку `YYYY-MM-DD`                           |
| `today()`         | Возвращает сегодняшнюю дату без времени                           |
