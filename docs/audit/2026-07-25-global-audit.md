   рыночный P&L −$35.9K. Разложение: временной распад −$38.7K, спред входа по ask на неликвидных

   (дальние OTM-стрэнглы, купленные по ask).
2. **Исправленный сегодня системный «оптимизм» прогноза** — эвристика роста IV

3. **«Плавающий» вход прогноза**: расширение TradingView молча перезаписывает ручной Fact IV
   заказчика рыночной IV и сохраняет в БД (для pending-сделок — автоматически при каждом
   открытии, без подтверждения; для свежих сделок подмена попадает и в снапшот Start P&L).
4. **Хрупкая якорная система Fact P&L**: цена якоря берётся из поля «Симуляция», ввод не

### P1 — модельные поправки (в сумме ~$50–200 на сделку)
- Крипто-режим: r=0 вместо форвардного базиса — $100–240 на сделку.
- Дивиденды: q=0 при выключенном тумблере/непрогруженном yield — $30–120.
- Экспирация как полночь UTC вместо 16:00 ET — $15–20 (основная часть медианной погрешности $20).
- Три часовые базы дат (UTC / локаль браузера / сервер) — риск ±1 день (после 19:00 в Панаме — стабильно).
- MAX прибыль / Risk/Reward — артефакт окна ±100% цены (не экстремум); «∞» показывается для убыточных конструкций; точка безубытка считается «на сегодня» без подписи даты.
- Fact IV и якорь не прокинуты в график/метрики — таблица и график расходятся.
- Предупреждение «Низкая ликвидность» всегда VERY_LOW (OI жёстко 0, volume 0) — сигнал бесполезен, фильтр подбора слеп.
- Серии-двойники (adjusted, вида {TICKER}1) неотличимы на всех шагах парсинга TradingView.

### P2 — методика и гигиена
- Аддитивная якорная поправка не затухает; при частичном закрытии позиции якорь масштабируется экономически неверно. Рекомендация: затухающая/мультипликативная поправка или калибровка implied vol по факту + вынос якоря в единую функцию с инвариант-тестами (7 копий сейчас).
- assetPriceAtEntry — цена из формы подбора (округлённая), а не рыночная (31 сделка); бьёт по P&L LONG-позиций БА и целям плана выхода.
- Мёртвый код: поверхность волатильности (~800 строк, включая старую эвристику роста — вернётся одним переименованием), OU-ветка недостижима, AI-волатильность — заглушки, 4 копии getEntryPrice, пятая копия BS в BinanceDealTab со своей ставкой.
- Американская поправка НЕ нужна (коллы — ровно $0, OTM-путы 0.8–1% премии).
