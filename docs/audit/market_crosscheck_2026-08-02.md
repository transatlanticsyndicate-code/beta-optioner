# Независимая сверка с биржей CBOE — 132 ноги / 50 сделок

**Дата анализа:** 2026-08-02 (воскресенье). Снимок CBOE `delayed_quotes` — состояние на закрытие последней торговой сессии, пятница 2026-07-31.

Код не менялся: только чтение выгрузки и расчёты.


## Методика

- Символ: `{ТИКЕР}{YYMMDD}{C|P}{страйк×1000}`. Все 132 ноги найдены в стандартной серии. Двойники скорректированных серий встретились только у CMCSA (`CMCS1` — не использовались).

- Рыночная цена ноги = мид `(bid+ask)/2` × количество × 100.

- Цена входа = `customAsk` при `isAskModified`, иначе `ask`, иначе `premium` (все 132 ноги — Buy).

- Расчёт платформы воспроизведён по `frontend/src/utils/blackScholes.js` + `optionPricing.js`: BSM, r = 4.5%, q — из `startSnapshot.dividendYield`, σ = `manualIvOverride` (Fact IV), T — дробные дни до 16:00 America/New_York (`dateUtils.getExpirationMomentET`), спот = `state.currentPrice`.
