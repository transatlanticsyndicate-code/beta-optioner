# Север GPT — двойная экспирация (2026-06-16)

## Что добавили
Возможность за один запуск подобрать комбинации сразу под **две** даты экспирации.
На форме настроек под полем даты экспирации появился чекбокс
**«Посчитать двойную экспирацию»** (по умолчанию снят). При включении ниже
появляется поле **«Альтернативная дата экспирации»**, по умолчанию заполненное
следующей экспирацией после основной.

Итог на экране результата: вместо двух вариантов — **четыре**, сгруппированные по
датам. Две группы одна под другой, каждая подписана своей датой экспирации; в
каждой — привычная пара «актив + опционы» / «только опционы».

## Поведение
- Чекбокс снят → всё работает как раньше (одиночный подбор, ответ той же формы).
- Альтернативная дата сама подстраивается под следующую после основной, пока
  пользователь не выберет её вручную; после ручного выбора — не меняется.
- Валидация: альтернативная дата обязательна, должна отличаться от основной и быть
  в списке доступных экспираций.

## Как устроено
- **Сбор данных:** цепочки по двум датам собираются последовательно через то же
  расширение (у него один слот команды и одна ячейка цепочки). P&L по каждому
  страйку считается отдельно под срок своей даты, затем строки объединяются в один
  список (каждая несёт свою дату).
- **Подбор:** для каждой даты выполняется отдельный запрос к ChatGPT тем же
  выверенным промптом и форматом (ровно две комбинации). Системный промпт **не
  менялся** — качество подбора по каждой дате идентично одиночному режиму. Два
  запроса идут на бэке **параллельно**, поэтому общее время — примерно как у одного
  подбора (~2–3 мин).
- **Стоимость:** двойной режим = два обращения к OpenAI за запуск (≈ двойной расход).
- **Применение к калькулятору не менялось:** каждая «нога» комбинации несёт свою
  дату экспирации, поэтому вариант с альтернативной датой применяется корректно.
