# IBKR Bridge v5.5

Расширение для Chrome, интегрирующее калькулятор опционов с терминалом Interactive Brokers. Работает и с Демо и с Live аккаунтами. Настройки терминала IBKR менять не нужно!

С версии **5.5** в строках базового актива есть и кнопки **открытия** позиций по акциям: зелёный `+` для LONG (BUY) и красный `−` для SHORT (SELL-short). Они показываются, когда в TWS позиции по этому тикеру и стороне ещё нет. Если позиция уже открыта — на этом же месте отображается серая `−` (закрытие, появилось в v5.4). Все ордера — staged LIMIT с live bid/ask из TWS, пользователь дожимает Submit вручную.

С версии **5.4** в калькуляторе можно закрывать позиции по акциям. Если в TWS есть позиция по тикеру в той же стороне (LONG/SHORT), что и строка в блоке «Базовый актив», рядом с типом позиции появляется серая кнопка `−`. Клик отправляет в TWS staged LIMIT-ордер: SELL по live bid (для LONG) или BUY по live ask (для SHORT). Цена берётся из TWS в момент клика — калькулятор её не знает.

С версии **5.3** кнопки в калькуляторе создают в TWS LIMIT-ордера (BUY @ Ask, SELL @ Bid). Если в строке нет Bid/Ask — кнопка визуально disabled. Кнопки в TradingView-чейне по-прежнему создают MKT-ордера.

## 🚀 Быстрый старт

### 1. Установка

Распакуйте архив в любую папку (Desktop, Documents — куда удобно). Скрипт запуска находит свои файлы относительно собственного расположения.

### 2. Запуск сервера

Дважды кликните на `Start IBKR Bridge.command`

> При **первом запуске** скрипт автоматически установит Python-зависимости (`aiohttp`, `ib_insync`). Нужен интернет.

### 3. Установка расширения Chrome

1. Удалите старое расширение
2. Нажмите "Загрузить распакованное расширение" (Load unpacked)
3. Выберите папку `IBKR_Bridge/extension`
4. Расширение установлено! ✅

### 4. Использование

1. Убедитесь, что TWS/IB Gateway запущен и подключен
2. Откройте калькулятор: https://beta.optioner.online/tools/universal-calculator
3. Заполните данные опциона (тикер, дата, страйк, количество)
4. Нажмите кнопку **+C** (Buy Call) или **-P** (Sell Put) и т.д.
5. Ордер появится в TWS! 🎉

### 5. Переключение Demo/Live

1. Кликните на иконку расширения в Chrome (справа от адресной строки)
2. Выберите режим:
   - 📝 **Demo** - бумажная торговля (порт 7497)
   - ⚠️ **Live** - реальные деньги (порт 7496)

⚠️ **ВАЖНО:** Убедитесь, что в TWS/IB Gateway вы вошли в соответствующий аккаунт!

## 📝 Changelog v5.5

- ✅ **Открытие позиций по акциям.** В строках блока «Базовый актив», по которым в TWS ещё нет совпадающей позиции, появляется кнопка открытия: зелёный `+` для LONG (BUY) или красный `−` для SHORT (SELL-short). Клик отправляет в TWS staged LMT-ордер с количеством из строки калькулятора. Цена — live bid/ask из TWS в момент клика. После того как ордер исполнится в TWS, кнопка автоматически переключается на серую `−` (закрытие).
- ℹ️ Backend не менялся — путь `secType=STK` в `/open` уже принимал любой `action`.

## 📝 Changelog v5.4

- ✅ **Закрытие позиций по акциям.** В блоке «Базовый актив» калькулятора рядом с LONG/SHORT появляется серая кнопка `−`, если в TWS есть совпадающая позиция по тикеру в той же стороне. Клик отправляет в TWS staged LMT-ордер с количеством, указанным в строке калькулятора. Цена — live bid/ask из TWS в момент клика (запрос идёт через bridge backend, расширение цену не передаёт).
- ✅ Эндпоинт `GET /positions` теперь включает позиции `secType=STK` (без полей expiry/strike/right).
- ✅ Эндпоинт `GET /open` поддерживает закрытие акций: `secType=STK&symbol=...&action=SELL|BUY&quantity=...` (без `price` — backend сам подставит live).
- ⚠️ Открытие позиций по акциям из калькулятора **не отправляется** — пользователь покупает акции вручную в TWS и вручную же фиксирует факт в калькуляторе.

## 📝 Changelog v5.1

- ✅ **Кнопки закрытия позиций.** На строках калькулятора, по которым в TWS уже открыта позиция, зелёная/красная кнопка автоматически заменяется на серую `−`. Клик по серой кнопке отправляет в TWS staged-ордер на закрытие позиции (противоположное направление, количество = реальный размер позиции в IB). Источник истины — реальные позиции IB, расширение опрашивает их каждые 5с.
- ✅ Новый bridge-эндпоинт `GET /positions` — отдаёт открытые опционные позиции из IB Gateway / TWS.
