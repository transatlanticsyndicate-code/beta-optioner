# IBKR Bridge v5.3

Расширение для Chrome, интегрирующее калькулятор опционов с терминалом Interactive Brokers. Работает и с Демо и с Live аккаунтами. Настройки терминала IBKR менять не нужно!

С версии **5.3** кнопки в калькуляторе создают в TWS LIMIT-ордера (BUY @ Ask, SELL @ Bid). Если в строке нет Bid/Ask — кнопка визуально disabled. Кнопки в TradingView-чейне по-прежнему создают MKT-ордера.

## 🚀 Быстрый старт

### 1. Установка

Распакуйте архив в любую папку (Desktop, Documents — куда удобно). Скрипт запуска находит свои файлы относительно собственного расположения.

### 2. Запуск сервера

Дважды кликните на `Start IBKR Bridge.command`

> При **первом запуске** скрипт автоматически установит Python-зависимости (`aiohttp`, `ib_insync`). Нужен интернет.

### 3. Установка расширения Chrome

1. Удалите старое расширение
2. Нажмите "Загрузить распакованное расширение" (Load unpacked)
3. Выберите папку `IBKR_Bridge/extension`
4. Расширение установлено! ✅

### 4. Использование

1. Убедитесь, что TWS/IB Gateway запущен и подключен
2. Откройте калькулятор: https://beta.optioner.online/tools/universal-calculator
3. Заполните данные опциона (тикер, дата, страйк, количество)
4. Нажмите кнопку **+C** (Buy Call) или **-P** (Sell Put) и т.д.
5. Ордер появится в TWS! 🎉

### 5. Переключение Demo/Live

1. Кликните на иконку расширения в Chrome (справа от адресной строки)
2. Выберите режим:
   - 📝 **Demo** - бумажная торговля (порт 7497)
   - ⚠️ **Live** - реальные деньги (порт 7496)

⚠️ **ВАЖНО:** Убедитесь, что в TWS/IB Gateway вы вошли в соответствующий аккаунт!

## 📝 Changelog v5.1

- ✅ **Кнопки закрытия позиций.** На строках калькулятора, по которым в TWS уже открыта позиция, зелёная/красная кнопка автоматически заменяется на серую `−`. Клик по серой кнопке отправляет в TWS staged-ордер на закрытие позиции (противоположное направление, количество = реальный размер позиции в IB). Источник истины — реальные позиции IB, расширение опрашивает их каждые 5с.
- ✅ Новый bridge-эндпоинт `GET /positions` — отдаёт открытые опционные позиции из IB Gateway / TWS.
