# Инструкция по запуску IBKR Bridge (DEMO)

> **Эта версия работает ТОЛЬКО с демо-аккаунтом (Paper Trading)**

## Предварительные требования

- macOS
- Python 3 (скачать: https://www.python.org/downloads/)

> Зависимости (`aiohttp`, `ib_insync`) ставятся автоматически при первом запуске скрипта `Start IBKR Bridge.command`.
> Если автоустановка не сработала — откройте **Терминал** и выполните вручную:
> ```
> pip3 install aiohttp ib_insync
> ```

---

## Что нужно запустить (по порядку)

### Шаг 1. Запустить TWS (Trader Workstation)

1. Открыть приложение **Trader Workstation** от Interactive Brokers
2. Войти в **paper trading** (демо) аккаунт
3. Убедиться что API включён:
   - Меню: **Edit → Global Configuration → API → Settings**
   - Галочка **Enable ActiveX and Socket Clients** — включена
   - **Socket port** = `7497`
   - Нажать **Apply / OK**

### Шаг 2. Запустить Bridge-сервер

Дважды кликнуть на файл **Start IBKR Bridge.command** внутри папки `IBKR_Bridge` (где бы она ни лежала).

> **При самом первом запуске** macOS может показать предупреждение:
> *«Apple cannot check it for malicious software»* / *«Невозможно проверить разработчика»*.
> Решение: **правый клик** (или Ctrl+клик) по файлу `Start IBKR Bridge.command` → **Открыть** → в диалоге снова нажать **Открыть**. Это нужно сделать один раз — потом будет работать обычным двойным кликом.

Или открыть **Терминал**, перейти в папку с проектом и запустить:
```
python3 main_source_backup.py
```

Если всё хорошо, в терминале появится:
```
Bridge Server running on http://localhost:5001
Connected to IBKR!
```

**Не закрывайте это окно терминала** — сервер работает пока оно открыто.

### Шаг 3. Установить расширение для браузера (один раз)

1. Открыть **Chrome** → ввести в адресной строке: `chrome://extensions`
2. Включить **Режим разработчика** (переключатель в правом верхнем углу)
3. Нажать **Загрузить распакованное расширение**
4. Выбрать папку `extension` внутри папки `IBKR_Bridge`

### Шаг 4. Открыть TradingView / Калькулятор

Перейти на страницу опционов в TradingView или на калькулятор `beta.optioner.online/tools/universal-calculator`. Расширение подключится к серверу автоматически.

## Как остановить

- Закрыть окно терминала (или нажать `Ctrl+C` в терминале)
- Закрыть TWS если не нужен

---

## Если что-то не работает

| Проблема | Решение |
|----------|---------|
| `ERR_CONNECTION_REFUSED` в консоли браузера | Сервер не запущен → выполнить Шаг 2 |
| `Not connected` / `ConnectionRefusedError` в терминале | TWS не запущен или API не включён → выполнить Шаг 1 |
| `Mapping not found` | Подождать 5 секунд после "Connected to IBKR!" и обновить страницу |
| `command not found: python3` | Установить Python: https://www.python.org/downloads/ |
| `No module named 'aiohttp'` | Выполнить: `pip3 install aiohttp ib_insync` |

## Порядок запуска (кратко)

1. **TWS** → войти в paper trading → проверить API на порту 7497
2. **Ярлык** → дважды кликнуть `Start IBKR Bridge.command` в папке `IBKR_Bridge`
3. **Браузер** → открыть/обновить страницу с опционами
