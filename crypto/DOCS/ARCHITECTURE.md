# Техническая документация: Crypto Position Manager
### Alex Ziemelis Edition by OPTIONER.ONLINE

Этот документ содержит описание архитектуры, логики и структуры проекта для обеспечения преемственности разработки.

## 1. Обзор проекта
Приложение является веб-версией сложной инвестиционной стратегии из Google Таблиц. Оно предназначено для расчета объемов дозакупок криптовалютных активов по заданным алгоритмам при падении цены.

## 2. Технологический стек
- **Сборка**: Vite
- **Язык**: TypeScript (Vanilla)
- **Стили**: Vanilla CSS (переменные для тем)
- **Хранение данных**: LocalStorage (ключ: `crypto_manager_state_v6`)

## 3. Структура файлов
- `/index.html`: Входная точка, структура UI, встраиваемый CSS для критических элементов (лого).
- `/src/style.css`: Основные стили в стиле GitHub/Vercel. Содержит токены тем (Dark/Light).
- `/src/engine.ts`: **Ядро расчетов**. Изолированная логика, не зависящая от DOM.
- `/src/main.ts`: **Контроллер приложения**. Управление состоянием, обработка событий, рендеринг DOM.
- `/public/`: Статические ресурсы (логотипы).

## 4. Логика расчетов (`engine.ts`)
Основная формула основана на рекурсивном вычете процентов от остатка:
- `S` (База) — начальный объем.
- `a` = S * %1
- `b` = (S - a) * %2
- `c` = (S - a - b) * %3
- `d` = (S - a - b - c) * %4

**Сумма остатка**: Остаток капитала в позиции в зависимости от выбранных шагов.
**Сумма дозакупки**: Общая сумма фактически вложенных средств (База - Остаток).

## 5. Ключевые функции UI
- **Редактирование депозита**: Двойной клик по числу депозита в шапке.
- **Статус активности**: Первый чекбокс (зеленый) включает/выключает актив из общих расчетов лимита.
- **Интерактивные итоги**: Итоговые суммы колонок рассчитываются динамически и выводятся прямо в `<thead>`.
- **Сценарии**: Индивидуальная настройка процентов для каждого из 4-х предустановленных сценариев (1500, 3000, 6000, 12000).

## 6. Темы
Реализованы через атрибут `[data-theme]` на `<html>`. Логотип инвертируется (белый/черный) автоматически через CSS-фильтры.
