# Задача: Кнопка "Отправить срезки на график"

## Контекст

В калькуляторе (вкладка **"Сделка"**) есть таблица **"План выхода"**, где для каждого опциона указана целевая цена. Пользователь хочет нажать одну кнопку — и расширение TradingView получит эти данные, чтобы нарисовать горизонтальные уровни (срезки) на графике актива.

Коммуникация калькулятор → расширение работает через **localStorage Command Bridge** (уже реализованный механизм): калькулятор пишет команду в `localStorage.tvc_refresh_command`, расширение читает её каждые 500ms.

---

## Задача для Андрея (сторона калькулятора)

### Что нужно сделать

Добавить кнопку **"Отправить срезки на график"** на вкладке "Сделка" (рядом с таблицей "План выхода") и при нажатии записать команду в `localStorage`.

---

## Команда: `send_srezki`

При нажатии кнопки записать в `localStorage`:

```javascript
localStorage.setItem('tvc_refresh_command', JSON.stringify({
  type: 'send_srezki',
  ticker: 'AMD',           // тикер текущего актива (строка, например "AMD", "AAPL", "SPY")
  srezki: [
    {
      option: 'Buy CALL 200 (24.04.26)',   // строка из колонки "Опцион"
      targetPrice: 229.38                  // число из колонки "Целевая цена $"
    },
    {
      option: 'Buy CALL 200 (24.04.26)',
      targetPrice: 259.30
    },
    // ... все строки из таблицы "План выхода"
  ],
  timestamp: Date.now(),
  processed: false
}));
```

### Поля команды

| Поле | Тип | Описание |
|------|-----|----------|
| `type` | string | Всегда `'send_srezki'` |
| `ticker` | string | Тикер актива (из заголовка сделки, например `"AMD"`) |
| `srezki` | array | Массив объектов — один элемент на каждую строку таблицы "План выхода" |
| `srezki[].option` | string | Текст из колонки "Опцион" (например `"Buy CALL 200 (24.04.26)"`) |
| `srezki[].targetPrice` | number | Число из колонки "Целевая цена $" (например `229.38`) |
| `timestamp` | number | `Date.now()` |
| `processed` | boolean | Всегда `false` при отправке |

### Что брать из интерфейса

Согласно скриншоту:

- **Тикер** — из шапки сделки (где написано "AMD", рядом с ценой $199.46)
- **Массив срезок** — из таблицы "План выхода", колонки:
  - "Опцион" → поле `option`
  - "Целевая цена $" → поле `targetPrice` (число, не строка)

Брать **все строки** таблицы (Шаг 1, Шаг 2, Шаг 3, Шаг 4 и т.д.).

---

## Жизненный цикл (UX-флоу)

```
1. Пользователь на вкладке "Сделка" заполнил таблицу "План выхода"
2. Нажимает кнопку "Отправить срезки на график"
   → кнопка исчезает, появляются две новые кнопки:
      [Перейти на график]   [Удалить срезки]
3. Нажимает "Перейти на график"
   → расширение открывает/переключается на вкладку TradingView с нужным тикером
4. Смотрит на график, видит нарисованные уровни
5. Когда срезки больше не нужны — нажимает "Удалить срезки"
   → расширение убирает линии с графика
```

---

## Команды: `go_to_chart` и `clear_srezki`

### Кнопка "Перейти на график"

```javascript
localStorage.setItem('tvc_refresh_command', JSON.stringify({
  type: 'go_to_chart',
  ticker: 'AMD',           // тикер текущего актива
  timestamp: Date.now(),
  processed: false
}));
```

### Кнопка "Удалить срезки"

```javascript
localStorage.setItem('tvc_refresh_command', JSON.stringify({
  type: 'clear_srezki',
  ticker: 'AMD',           // тикер текущего актива
  timestamp: Date.now(),
  processed: false
}));
```

### Поля команд `go_to_chart` и `clear_srezki`

| Поле | Тип | Описание |
|------|-----|----------|
| `type` | string | `'go_to_chart'` или `'clear_srezki'` |
| `ticker` | string | Тикер актива (тот же, что был в `send_srezki`) |
| `timestamp` | number | `Date.now()` |
| `processed` | boolean | Всегда `false` при отправке |

---

## Что НЕ нужно делать Андрею

- Не нужно ждать ответа от расширения (все команды fire-and-forget)
- Не нужно читать `tvc_refresh_result`
- Не нужно самому открывать TradingView — это сделает расширение само

---

## Что сделает расширение (после выполнения задачи Андрея)

- `send_srezki` → нарисует горизонтальные линии на уровне каждого `targetPrice`
- `go_to_chart` → найдёт/откроет вкладку TradingView с графиком тикера
- `clear_srezki` → удалит все нарисованные срезки для данного тикера

## Приёмка

Задача считается выполненной, когда:

**Кнопка "Отправить срезки на график":**
- [ ] Кнопка видна на вкладке "Сделка" (рядом с таблицей "План выхода")
- [ ] При нажатии в `localStorage` появляется объект с `type: 'send_srezki'`
- [ ] Объект содержит корректный `ticker` (строка)
- [ ] Объект содержит массив `srezki` с полями `option` (строка) и `targetPrice` (число)
- [ ] `processed: false` при записи
- [ ] После нажатия кнопка исчезает, появляются две кнопки: "Перейти на график" и "Удалить срезки"

**Кнопка "Перейти на график":**
- [ ] Кнопка появляется после отправки срезок
- [ ] При нажатии в `localStorage` появляется объект с `type: 'go_to_chart'`
- [ ] Объект содержит корректный `ticker` (строка)
- [ ] `processed: false` при записи

**Кнопка "Удалить срезки":**
- [ ] Кнопка появляется после отправки срезок
- [ ] При нажатии в `localStorage` появляется объект с `type: 'clear_srezki'`
- [ ] Объект содержит корректный `ticker` (строка)
- [ ] `processed: false` при записи
